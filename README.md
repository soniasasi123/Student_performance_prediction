# Student Performance Prediction using XGBoost

## Project Overview

This project predicts student academic performance using the XGBoost machine learning algorithm. The model analyzes academic, demographic, and behavioral factors to estimate a student's final score and identify key factors that influence performance.

The goal is to help educational institutions identify students who may require additional support and enable data-driven decision-making.

---

## Problem Statement

Educational institutions often struggle to identify students at risk of poor academic performance until after examinations are completed.

This project aims to build a predictive model that can estimate student performance based on factors such as:

- Study time
- Attendance
- Previous grades
- Parent education level
- Internet access
- Extracurricular activities

By predicting student outcomes early, educators can implement timely interventions.

---

## Dataset

Dataset Source:

UCI Student Performance Dataset

Features include:

| Feature | Description |
|----------|------------|
| Study Time | Weekly study hours |
| Attendance | Attendance percentage |
| Previous Grades | Historical academic scores |
| Parent Education | Education level of parents |
| Internet Access | Availability of internet at home |
| Activities | Participation in extracurricular activities |
| Final Score | Target variable |
